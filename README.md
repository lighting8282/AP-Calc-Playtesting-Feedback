# AP Calc: Playtesting Feedback

The public home for playtesting **AP Calc**, a calculator duel game: you're shown a target, and you
build an expression that equals it before your opponent's timer runs out. Clever answers hit harder.
Win duels to make your way from high school through college, choose a major, and earn your degrees.

This repository is where playtest feedback lives: what testers asked, what they found, and what
was done about it.

## The goal

To make AP Calc as clear, fair and fun as it can be, by watching how real players get on with it:
- **Is it clear?** Do people understand what to do in their first duel, on the map and in the shop?
- **Is it fair?** Are fights too hard, too easy or uneven? Does the game ever reject a right answer?
- **Is it fun?** What keeps people playing, and what makes them stop?

Every round of testing ends in changes to the game, and this repo keeps the record of them.

## Taking part

Playtests run in the browser on an invite-only itch.io page. If you've been invited, you'll have the
link and the password. If you'd like to take part in a future round, open an issue saying so.

## Reporting something

The quickest way during a playtest is the **Feedback** button in the bottom-left corner of the game,
which opens a short form. You can also [open an issue](../../issues/new/choose):
- **Bug report:** something broke, looked wrong, or rejected an answer you think was right.
- **Feedback or suggestion:** anything about difficulty, clarity, pacing, the shop, or how it feels.

A screenshot helps a lot: the build version is printed in the bottom-left corner of every screen
(for example `PLAYTEST v0.4.0-pt.2611251227`), so we know exactly which build it came from.

## Privacy

Nothing personal is published here. Testers aren't named unless they ask to be. The game itself only
sends anonymous play stats, and only if the player chooses **Share stats** when it asks.

## About the game

AP Calc is in development. The game's source code isn't in this repository; this one is only for
playtesting and feedback.
